# Attack Scenario 01 - PowerShell EncodedCommand

## Описание

Для первого сценария я решил проверить, насколько хорошо настроенный Wazuh обнаруживает запуск PowerShell с закодированными командами.

В качестве цели использовал свой доменный контроллер `DC01` (Windows Server 2022). Мне было важно не просто получить событие в SIEM, а самостоятельно разработать правило обнаружения, проверить его на практике и убедиться, что оно действительно работает.

**MITRE ATT&CK:** T1059.001 - PowerShell

## Проведение теста

Для симуляции я использовал следующую команду:

```
$c = [Convert]::ToBase64String([Text.Encoding]::Unicode.GetBytes('Write-Output "PURPLE_LAB_TEST"')); powershell.exe -NoProfile -EncodedCommand $c
```

Она преобразует обычную команду PowerShell в Base64 и запускает её через параметр `-EncodedCommand`.

В качестве тестовой нагрузки я выбрал простую инструкцию `Write-Output "PURPLE_LAB_TEST"`. Она не выполняет никаких изменений в системе и нужна только для проверки обнаружения.

## Сбор событий

После запуска команды Sysmon зарегистрировал создание нового процесса (Event ID 1 - Process Create).

Я проверил, что событие содержит командную строку с параметром `-EncodedCommand`, а затем убедился, что Wazuh Agent передаёт телеметрию с `DC01` на мой сервер мониторинга `WAZUH01`.

## Обнаружение

Для обнаружения я использовал собственное правило Wazuh `100100`, которое разработал и добавил в `local_rules.xml`.

Его задача - искать в командной строке PowerShell параметры `-enc` и `-EncodedCommand`.

После запуска теста я получил алерт в Wazuh Dashboard:

|Параметр|Значение|
|---|---|
|Агент|DC01|
|ID агента|001|
|ID правила|100100|
|Уровень|8|
|Sysmon Event ID|1|
|MITRE ATT&CK|T1059.001|

В JSON-событии я увидел срабатывание именно своего правила с описанием `PowerShell executed with EncodedCommand parameter`.

Дополнительно на ту же активность сработало штатное правило Wazuh `92057` уровня 12. Получилось сравнить собственное обнаружение со встроенным механизмом SIEM.

## Что получилось

В результате я подтвердил, что вся цепочка работает:

1. Запускаю тестовую команду на `DC01`.
    
2. Sysmon фиксирует создание процесса.
    
3. Wazuh Agent отправляет событие на `WAZUH01`.
    
4. Wazuh Manager анализирует его.
    
5. Моё правило `100100` обнаруживает нужный параметр.
    
6. В Dashboard появляется соответствующий алерт.
    

Для меня это был важный этап проекта: я не просто использовал готовые правила Wazuh, а написал собственное, проверил его на реальном событии из своей лаборатории и получил ожидаемый результат.

## Итог

Первый сценарий успешно завершён. Мне удалось обнаружить запуск PowerShell с закодированной командой с помощью собственного правила Wazuh.

Дополнительно сработало штатное правило `92057`, что позволило подтвердить обнаружение двумя разными правилами.

**MITRE ATT&CK:** T1059.001 - PowerShell.
